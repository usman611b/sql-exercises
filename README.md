# SQL Exercises

Original SQL practice files from my Big Data Analytics training. Most use **Microsoft SQL Server / T-SQL**. Select individual exercises in SSMS rather than executing an entire file as a deployment script: files contain repeated setup statements and alternative attempts, and some sections are unfinished.

| File | Main topics |
| --- | --- |
| [SQLQuery1.sql](SQLQuery1.sql) | Table creation, inserts, updates, ALTER TABLE, and GETDATE |
| [SQLQuery2.sql](SQLQuery2.sql) | String concatenation, CAST, arithmetic, and CASE |
| [SQLQuery3.sql](SQLQuery3.sql) | Temporary tables, sales joins, aggregation, HAVING, and ranking |
| [SQLQuery4.sql](SQLQuery4.sql) | Extended practice with sales queries, CTEs, joins, and transformations |
| [SQLQuery5.sql](SQLQuery5.sql) | Invoice parent relationships, self-joins, and dimension-key updates |
| [SQLQuery7_Window_func.sql](SQLQuery7_Window_func.sql) | OVER, PARTITION BY, ROW_NUMBER, and salary analysis |
| [SQLQuery8_TSQL_questions.sql](SQLQuery8_TSQL_questions.sql) | Stored procedures, views, DENSE_RANK, and sales-report formatting |
| [SQLQuery9_TSQL_questions.sql](SQLQuery9_TSQL_questions.sql) | Recursive CTE practice to repeat student rows |

Sales exercises referencing FactInternetSales and DimSalesTerritory require matching AdventureWorks data warehouse tables. Other exercises create small practice tables. Use a disposable practice database because the scripts include table creation, updates, and drops.

These files preserve learning work, including intermediate attempts. They have not been verified as complete runnable batches in this publishing environment.
